fraud-lakehouse

Real-time card fraud detection on one laptop: Kafka, Spark Structured Streaming, Iceberg, dbt.

data data moving now schedule files and metadata running starting stopped failed Click a card for its role, ports, links and tables.

  1. Ingest. The producer replays the Kaggle CSV into the Kafka topic transactions, keyed by card, at RATE events per second.
  2. Process. Spark Structured Streaming reads Kafka in micro-batches, appends each message to Bronze and merges clean rows into Silver. Every 10 min Airflow runs dbt to rebuild Gold.
  3. Store. Bronze, Silver and Gold are Iceberg tables: Parquet files in MinIO, table names in the Hive Metastore, whose own data sits in PostgreSQL.
  4. Serve. Metabase and Beeline query the tables through the Thrift Server; Jupyter reads them with PySpark.
